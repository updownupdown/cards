# Cover art alternates

Second choices for the cover art picked in October 2026. To use one, copy it
over the game's image in `assets/thumbnails-source` (keeping the game's file
name, e.g. `Crossword.jpg`), put its credit in the game's file in
`src/data/games`, update the game's line in `src/data/artworks.ts`, and run
`npm run thumbnails:convert`.
