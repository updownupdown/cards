Notes

Card sizes, confidence and costs

How the card sizes are used

Each size is a full set of 56 faces at 500 × 700, drawn as a separate Figma frame set.

  • Classic is used by one game (Rogue Run) and costs 740 KB and a fourth set to maintain. Regular has the same room for large pips and courts, so I'd move Rogue Run to Regular and drop Classic.
  • Small, Tableau and Regular each earn their place: Small for dense grids (47 games), Tableau where cards overlap in columns and only the top strip shows (28), Regular for spread-out layouts with room (17).
  • Worth an audit: a few Regular games stack cards in columns much like Tableau games do; moving those to Tableau makes the suit visible on every overlapped card. Spider Solitaire uses Small or Tableau depending on its variant, which is right.
  • Make the sizes one design with three layouts. The layout switch above draws all three from the same suits, numerals and courts. Built that way in Figma (variants of one component, not three drawings), the sizes can't drift apart.

How consistent can I make them?

Suits aloneHigh
Numerals aloneHigh
Stylised courtsGood
Detailed courtsLow
  • Suits and numerals: very confident. They are vector shapes on one fixed grid, generated from a single definition, so every size and colour is geometrically identical. For Figma I'd deliver numerals converted to outlines, on a shared baseline and cap height, so no font needs installing.
  • Stylised courts (the ones on this page): confident. They are built from one figure per rank in a given style, so the four suits and three sizes stay in step. They're a starting point to refine, not finished art.
  • Richly illustrated courts like today's (hand-drawn figures with ornament, mirrored top and bottom): not something I'd promise at that quality. I can lay out the figures, symmetry and colour rules and produce clean vector drafts, but the finish needs an illustrator's pass.
