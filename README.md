# SoloSuite: a collection of solo playing card games.

<a href="https://solosuite.app">Play</a>

## Development

- `npm test` runs the Jest unit and simulation suite.
- `npm run test:watch` runs tests while developing.
- `npm run test:coverage` writes a coverage report.
- [Testing card games](docs/testing.md) describes the game-model framework and adoption workflow.
